# BCF6 的训练与推理逻辑

依据：[原论文 arXiv v2](https://arxiv.org/html/2311.16121v2)，§3–§6.2 与表 1。本文使用论文的 $T_{\theta_i}$、$f_\eta$、$\mathcal F$ 和 $\mathcal G$ 记号。BCf 是原论文名称；BCF6 是后续文献对该 BC6 路线的称呼。

本文介绍论文的方法。当前源码对未公开细节作了补充选择，尤其是连续端点坐标和反量化延拓并非式 (7)–(9) 的逐式移植；请对照[逐项设置审计](PAPER_SETTINGS_AUDIT_ZH.md)阅读，区分论文设定与本仓库实现。

## 1. 每个材质实际保存什么

**Block-Compressed Features（BCf / BCF6）** 为每个材质学习四组特征纹理 $T_{\theta_0},\ldots,T_{\theta_3}$，每组 3 通道，并学习一个小型解码 MLP $f_\eta$。特征的三个通道是潜变量，不是材质的 RGB。每组纹理包含多个 mip；每级 mip 有自己的可训练参数。

给定纹理坐标 $(u,v)$ 与采样尺度 $s$，从四组特征中取样、拼接为 12 维向量，再送入 MLP。论文式 (3) 为：

$$
\mathcal G_{\theta,\eta}(u,v,s)=f_\eta\big(T_{\theta_0}(u,v,s),\ldots,T_{\theta_3}(u,v,s)\big).
$$

网络采用一个 16 维隐藏层和 ReLU，结构是 **12→16→c**。$c$ 由材质输出通道决定。普通 albedo + normal XY + ARM 为 8 输出；有位移时可增加输出。UV 与尺度在此结构中控制纹理采样，不作为额外坐标编码拼到 12 维网络输入。

这是逐材质优化：新材质有自己的特征和网络。训练后保存压缩特征及解码器，而不是保存一个对所有材质通用的图像编码器。

## 2. BC6H 块如何参与训练

每个 4×4 特征块使用两个分区、两条三维线段。参数为四个三维端点 $e_1,e_2,e_3,e_4$、16 个连续索引变量 $x_j$，以及从 32 种预定义形状中选出的分区编号 $k$。分区决定每个 texel 使用哪条线段，索引决定其在线段上的位置（§4.1，式 (6)）。

训练前向模拟 BC6 的解码链：端点反量化 → 按分区和索引混合端点 → 将结果转换到 half 所表示的数值域（§4.2，式 (7)–(9)）。反向通过这条可微模拟路径更新端点和连续索引；分区在主训练阶段固定。

这里的插值涉及 BC6 的编码数值域及 half 转换，复现必须保留这一数值映射。训练的连续模型与最终整数位流分别验收。真实导出按 [Microsoft BC6H 规范](https://learn.microsoft.com/en-us/windows/win32/direct3d11/bc6h-format) 实现符号、舍入、插值权重和 fix-up anchor 等规则。

论文导出使用每分量 6-bit 端点、3-bit 索引。结合规范，这对应双分区 Mode 10：5 位模式 + 5 位分区 + 72 位端点 + 46 位索引 = 128 位。16 个 3-bit 索引中两个 anchor 各少存一位，因此索引区是 46 位。Mode 10 的识别来自论文位宽与标准表的对应，原文未直接使用这个模式编号。

## 3. 训练的三个阶段

训练目标是论文式 (5) 的材质重建平方误差；实现说明使用 batch 内的 MSE：

$$
\mathcal L(\theta,\eta)=\frac{1}{|B|}\sum_{(u,v,s)\in B}
\left\|\mathcal G_{\theta,\eta}(u,v,s)-\mathcal F(M)(u,v,s)\right\|_2^2.
$$

若实现还对 $c$ 个通道取均值，需固定该归一化并记录，以免改变相同学习率下的梯度尺度。

参考材质 $\mathcal F(M)$ 在相邻两个 mip 内分别做 bicubic 采样，再沿尺度线性混合。特征侧在两个相邻 mip 内做 bilinear 采样，再混合，即 trilinear 采样。论文使用 512×512 个 UV 采样位置，并为每批随机采样连续尺度。这使模型学习连续位置和尺度下的过滤材质，而不只拟合 mip0 的整数像素中心。

| 阶段 | 步数 | 更新的参数 | 特征 / MLP 初始学习率 | 指数衰减系数 |
|---|---:|---|---|---|
| 自由特征预训练 | 5,000 | 无块约束的各级特征、MLP | 0.05 / 0.001 | 0.9995 |
| 块约束主训练 | 200,000 | 端点、连续索引、MLP；分区固定 | 0.01 / 0.001 | 0.9999 |
| 量化后微调 | 1,000 | 固定量化特征，只更新 MLP | 原文未给独立数值 | 原文未给独立数值 |

优化器为 Adam。两阶段边界处，将预训练特征用 BC6 编码，再提取分区、端点与索引，作为主训练初始化。主训练结束后才对端点、索引作最终量化，并冻结特征进行解码器微调（§6.2）。

§6.1 的 205k 指 5k+200k；加上 §6.2 的 1k 微调，完整流程为 **206k 次更新**。第三阶段学习率、Adam 状态如何衔接、scheduler 的调用间隔等，将在实现时明确记录，并区分论文披露值与复现选择。

```mermaid
flowchart LR
    A[单材质及参考 mip] --> B[自由特征与 MLP 联训 5k]
    B --> C[BC6 编码初始化并固定分区]
    C --> D[端点与连续索引及 MLP 联训 200k]
    D --> E[端点和索引量化并冻结]
    E --> F[仅 MLP 微调 1k]
    F --> G[BC6H mip 纹理和 FP16 网络]
    G --> H[独立重载解码与评分]
```

## 4. 推理怎样执行

1. GPU 常驻四张带 mip 的 BC6H 特征纹理及 FP16 网络权重缓冲。
2. 根据屏幕空间 UV 导数以及各特征纹理尺寸，确定各自的 LOD。不同分辨率的特征需要相应尺度偏移（§5.2，式 (11)）。
3. 硬件纹理单元解压访问到的 BC6H 块，并执行 trilinear 过滤。四个采样结果合成 12 维特征。
4. shader 执行一次 12→16→c 的 MLP，输出 albedo、normal、AO、roughness、metalness 等材质属性。
5. 常规 PBR 着色器根据这些属性、光照和几何计算最终颜色。采用 XY 法线配置时按约定重建 Z。

一次 MLP 查询前已经完成特征过滤，模型训练又包含连续尺度的监督，因此该设计以一次解码输出过滤后的材质。硬件采样内部仍会访问邻近 texel 与 mip；“一次 MLP”不等于只读取一个 texel。

```mermaid
flowchart LR
    A[UV 和屏幕导数] --> B[四张 BC6H 特征的硬件采样]
    B --> C[拼接 12 维特征]
    C --> D[12 到 16 到 c 的 MLP]
    D --> E[PBR 材质属性]
    E --> F[常规光照着色]
```

## 5. 论文的四档配置

表中数字为每组方形特征的边长；括号为论文表 1 的 mips 数值。

| 配置 | T0 | T1 | T2 | T3 |
|---|---:|---:|---:|---:|
| BCf-0.5K | 512 (8) | 256 (7) | 128 (6) | 64 (5) |
| BCf-1K | 1024 (9) | 512 (8) | 256 (7) | 128 (6) |
| BCf-2K | 2048 (10) | 1024 (9) | 512 (8) | 256 (7) |
| BCf-2K++ | 2048 (10) | 2048 (10) | 512 (8) | 256 (7) |

BC6H 每个 4×4 块为 16 字节，即每张特征纹理每 texel 8 bit，而不是整套材质固定 8 bpp。材质码率还取决于四组分辨率、所有已保存 mip、网络参数及数值侧信息。实际部署包必须逐项计数。
