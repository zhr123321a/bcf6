# 论文设置与当前实现逐项审计（R03）

2026-10-26（北京时间）。依据 [arXiv 2311.16121v2](https://arxiv.org/html/2311.16121v2)，对照 `train.py`、`model.py`、`codec.py`、`deployment.py`。当前证据支持“论文明确配置 + 已披露的补充选择”，尚不支持与作者内部实现完全一致。

R03 更正激活函数的归属：原文只称 MLP 使用 ReLU，未逐层说明，不能将“隐藏层 ReLU”单独列为作者明确设置。当前隐藏 ReLU、线性输出的数值实现不变；本次只修正说明。

### LR 行为

主阶段第 t 次更新后 LR 为 `.01*.9999**t` 和 `.001*.9999**t`。t=200000 时约 **2.06e-11 / 2.06e-12**，最后1k再重置 MLP LR。该结果可由源码确定；作者是否同样调用、后半段能带来多少保存质量提升仍需核实/评价。本次注释更新保留原数值行为，没有为加速修改 LR 或步数。

### 连续训练与标准部署

`FeatureMip.texture` 在连续前向中省去标准整数舍入，以获得端点/索引梯度；`freeze_quantized`、`codec.decode_parameters` 和 DDS 使用标准整数规则。8192个随机块与独立 bcdec 精确一致验证的是**离散编解码**，不能证明训练梯度与作者实现一致。
