# BCF6 独立复现 R01

记录日期：2026-10-26（北京时间）。本版在仓库初始规格之后实现了训练与保存验证链。论文依据为 [Real-Time Neural Materials using Block-Compressed Features](https://arxiv.org/html/2311.16121v2)，§3–§6.2 与表 1。

## 已执行的验证

- Linux / GCC 11.4 编译独立 C++ 解码器；PyTorch 2.7.1+cu118 环境的 6 项测试通过（原 5 项及新增恢复检查）。
- 随机测试 8,192 个 Mode 10 块，覆盖 signed/unsigned、32 个分区、anchor 交换及端点极值。Python 编解码与独立 `bcdec` 的浮点结果精确一致。
- 检查连续 half 映射的值与导数、端点/索引梯度、训练阶段转换、DDS 保存/重载、FP16 权重舍入、再次导出的文件身份，以及损坏文件拒绝。
- 在 CPU 合成样例上分别验证 warmup、block、finetune 的 checkpoint 续训：恢复模型、Adam、scheduler 和 RNG 后，下一次更新的损失及全部模型状态与连续执行逐元素相等。
- 在 lubricant_spray 原始 2048×2048 RGB9 目标上完成 1K / 8 输出的 20+20+5 步 CUDA 短程训练，batch 为 512×512。2026-10-26 12:25:16（北京时间）完成保存和独立重载；实际数值载荷 1,857,520 字节，即 3.542938232421875 bpp。
- 同一保存产物的全 mip0、原域 RGB9 CPU/GPU 重放：max abs = 5.960464477539063e-8，RMS = 1.0322176770788189e-9，`pixel_strict_pass=true`、`strict_pass=true`。该结果验证保存链；45 步短程训练不用于论文质量比较。

正式任务采用同一材质、1K、8 输出、seed 1、5,000+200,000+1,000 步。2026-10-26 12:24:28（北京时间）登记持久队列，短程验证通过后，于 12:31:36（北京时间）获得 GPU 1 并启动。12:33:41（北京时间）的快照为 warmup 5,000/5,000、block 900/200,000；完整保存质量尚未生成。此前 5 次资源准入等待保留在调度历史中。

首轮范围为一个材质、一个配置；队列最多占一个 GPU，遵守现有全局 6 物理 GPU / 32 CPU 上限，每任务 2 CPU 线程，并保留外部进程。调度器独立于本地电脑运行，成功结果缓存复用。冻结运行源码的组合 SHA256 为 `d411dd3218ff8606c5ef28c6635dba207d4489d648e42a5fae64d1e5478eaf54`，由 Python 模块、C++ 包装器及 `bcdec.h` 的逐文件 SHA256 清单计算。

## 论文设置与本次选择

| 项目 | 本次实现与证据范围 |
|---|---|
| 表示及网络 | 论文四组 RGB 特征、独立 mip、12→16→c；隐藏层 ReLU。本实现选择线性输出。 |
| 主训练流程 | 5k 自由特征→BC6 初始化/固定分区→200k 端点、连续索引与 MLP→量化冻结特征→1k MLP。 |
| 损失与采样 | batch/通道均值 MSE；每批 512² 个 IID 均匀 UV、一个均匀连续尺度。参考 bicubic+LOD，特征 bilinear+LOD。UV 的 IID 排列为本次选择。 |
| BC6 格式 | 论文双分区 6-bit 端点、3-bit 索引对应规范 Mode 10。本次选择 signed BC6H SF16；论文实验 signedness 尚未核实。 |
| 初始化编码器 | 本实现对全部 32 个分区做 half-code 域 PCA 线拟合，以精确 BC6H palette 的浮点误差选最优分区。论文未指定可复用编码器。 |
| 连续参数 | 端点用连续 signed 6-bit code 坐标，分段线性反量化；索引是 [0,1] 连续插值权重。训练后端点舍入、索引映射到标准 3-bit 权重，随后按标准整数解码冻结。 |
| Adam 与 LR | 论文给出的特征/MLP 初值为 .05/.001（warmup）、.01/.001（block），gamma .9995/.9999。本实现每 update 衰减、阶段切换重建 Adam；beta=.9/.999、epsilon=1e-8。这些调用约定并非论文已公开细节。 |
| 最后 1k 步 | 仅训练 MLP；本实现重置 LR=.001、gamma=.9999。论文给出步数与冻结要求，未给出这些独立超参数。 |
| mip/边界 | 参考用 2×2 平均生成 mip；特征按表 1 截止 4×4；border 边界、align_corners=False、按特征尺寸设置 LOD bias。均写入协议。 |
| 精度与保存 | FP32 训练、TF32 关闭；BC6H 块和 FP16 网络保存。重载评分用保存的 FP16 权重执行 FP32 算术。 |
| 数据适配 | 8 输出监督 Diffuse RGB、Normal XY、ORM。由预测 XY 重建正 Z 后另报 RGB9，且保留 8 通道质量；9 输出是单独变体。 |

本仓库是依据论文实现的可运行基线。上述未公开细节使其与作者内部实现的逐步等价性尚不能确认；这些选择随每次运行写入 `protocol.json`，源码、目标及部署文件各有 SHA256。训练使用冻结的源码副本，后续仓库修改不会热更新正在运行的任务。
