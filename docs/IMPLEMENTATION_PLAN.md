# 实现顺序与验收

2026-10-26（北京时间）：以下为待实现清单，仓库尚无可运行训练入口。

1. **标准 BC6H 基础。** 实现 Mode 10 打包和独立 CPU 解码；固定 32 种分区、anchor 索引、端点符号和极值处理。用已知块与独立解码器覆盖零值、负值、最大有限值、端点交换及所有分区。导出器不能调用一次任意模式压缩后把结果当作已学习参数的原样保存。
2. **连续特征与采样。** 实现四组独立 mip 参数、bilinear/trilinear 特征采样、bicubic+LOD 参考采样、12→16→c ReLU 解码器和 MSE。核对像素中心、边界、LOD bias、非方形材质以及最末 mip。
3. **完整训练状态。** 实现 5k 自由特征初始化、BC6 分区/参数提取、200k 固定分区块训练、量化后 1k 解码器微调。保存随机数、优化器、scheduler、阶段和数据身份，使恢复与连续运行可比较。
4. **真实部署文件。** 保存带 mip 的 BC6H DDS 与 FP16 解码器，并从这些文件单独重载。分别记录连续训练模型、量化模型、FP16 保存模型与重载结果；最终质量取重载产物。
5. **数据集与批量评测。** 绑定现有 external-25 frozen inputs，先完成单场保存审计，再登记批量任务。复用持久调度、实际字节审计和原域 RGB9 评分，报告实际分母。
6. **运行时。** 实现硬件 BC6H 采样及 shader MLP。Linux 和 Windows 分别验证同一源码/保存产物；吞吐测试记录 GPU、分辨率、LOD、过滤方式及计时范围。

## 实现前需固定的细节

| 细节 | 当前证据与处理 |
|---|---|
| Signed / unsigned BC6H | 原文给出了两种映射，已核查章节未明确实验采用哪一种。通过作者资源或独立验证选定并显式记录，不能静默假定。 |
| Mode 10 | 论文的双分区 6-bit 端点 / 3-bit 索引与 Microsoft Mode 10 对应；模式编号是规范映射结论。 |
| 可微公式与精确整数解码 | 式 (7)–(9)说明训练模型；标准位流必须另按整数规则验证，特别是符号、极值、权重表及舍入。 |
| 表 1 的 mips 数量 | 记录原表数值；如解释为含基础层的数量，则各方形链到 4×4 结束。实现时将总层数和每层尺寸全部显式列出，核对保存容量。 |
| 初始化与量化 | 需固定初始化 BC6 编码器、模式限制、端点坐标表示、连续索引到标准权重的映射、约束/裁剪方法。 |
| Adam 和 scheduler | 论文给出初始 LR 和 gamma，未完整说明阶段切换的 optimizer 状态及 scheduler 调用间隔。公开规格将未核实项置 null。 |
| 量化后 1k 微调 | 步数与冻结特征有文献依据；独立 LR、scheduler 重置及 FP16 权重舍入时机待实现时明确。 |
| 参考 mip、UV 边界与输出激活 | 主文给出采样滤波与 ReLU MLP，但这些底层约定需要记录。保留证据与实现选择的区别。 |
